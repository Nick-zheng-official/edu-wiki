# 作文

## 议论文基本要素

高考作文普遍建议写议论文. 议论文三大要素为论点, 论据, 论证. 简单来说, 论点是文章的观点看法, 分为中心论点与分论点. 一篇作文一般只有一个中心论点, 但可以由中心论点拆分出多个分论点, 用以支撑中心论点. 那么, 如何证明论点的正确性? 借助论据, 即议论时的"证据". 论据分为事实论据与道理论据, 事实论据包括事例与数据, 而道理论据一般为名人名言, 俗语格言, 权威意见, 或公认的常识与普遍规律等. 想要令论据服务于论点需要一定的过程及方法, 即论证与论证方法. 常见的论证方法有:

1. 举例论证: 即举典型事例来证明观点. 
2. 道理论证(引用论证): 引用名人名言, 俗语格言等来证明观点.
3. 对比论证: 把两种相似或相对的事物, 观点放在一起进行比较. 既可横向对比(不同对象间)也可纵向对比(同一对象的前后变化). 
4. 比喻论证: 寻找通俗易懂且存在本质上的相似点的喻体, 进行比喻.
5. 因果论证: 阐明何种原因导致了特定结果, 或由既定结果追溯其产生原因.
6. 类比论证: 将多个本质不同, 但某些属性相似的对象进行比较, 由其一具有此属性从而得到另一也可能具有此属性.  
7. 假设论证(归谬法):  先假设事件没发生, 从反面推得造成的后果与影响; 或在驳论文中, 假设对方观点正确, 直到推出一个明显荒谬, 违背常理的结论, 从而反证对方观点错误. 
8. 数据论证: 列出准确, 具体的数据.

可以发现, 作文素材是必要的, 但不是唯一的. 其不是唯一决定文章质量的因素, 甚至可以说不是决定性因素.

## 评分细则

这里给出评分细则: 

| 评分维度 | 一等 (20~16分) | 二等 (15~11分) | 三等 (10~6分) | 四等 (5~0分) |
| :--- | :--- | :--- | :--- | :--- |
| 内容 (20分, 基础等级) | 符合题意；中心突出；内容充实；思想健康；感情真挚 | 符合题意；主题明确；内容较充实；思想健康；感情真实 | 基本符合题意；中心基本明确；内容单薄；思想基本健康；感情基本真实 | 偏离题意；中心不明确；内容不当；思想不健康；感情虚假 |
| 表达 (20分, 基础等级) | 符合文体要求；结构严谨；语言流畅；字迹工整 | 符合文体要求；结构完整；语言通顺；字迹清楚 | 基本符合文体要求；结构基本完整；语言基本通顺；字迹基本清楚 | 不符合文体要求；结构混乱；语言不通顺语病多；字迹潦草难辨 |
| 特征 (20分, 发展等级) | 深刻；丰富；有文采；有创意 | 较深刻；较丰富；较有文采；较有创意 | 略显深刻；略显丰富；略显文采；略显创意 | 个别语句有深意；个别例子较好；个别语句较精彩；个别地方有深意 |

很多人没有注意到的是, 除了以上表格外, 官方还做出了一些文字说明. 简单来说, 内容最重要, 表达次之, 特征作为发展等级. 在内容上, 普通的作文一般给到二等. 表达的评价需要参考内容的等级, 不能跨等给分, 如内容为二等, 则表达可为二等, 一等或三等, 不能为四等. 类似地, 发展等级的评价要与基础等级匹配, 即发展等级不能跨越基础等级, 如内容为二等, 表达为二等, 则发展等级原则上不超过二等. 这也是大多数同学作文得分较为稳定的原因. 

实际上, 表格中的介绍十分笼统. 具体来说, 以一等为例, 符合题意意味着你需要审题全面; 中心突出意味着你需要反复点题; 内容充实意味着你需要有丰富的, 不同角度的分论点与论据; 思想健康即你不能使用不当言论; 情感真挚即你可能需要对事例添加自己在看见此事件时的心理感受. 符合文体要求与结构严谨是写作的必要前提, 具体详见下文; 语言流畅就是字面意思; 字迹工整仅要求工整而非美观(当然美观更好), 字迹对得分的纸面影响不超 3 分, 但对于阅卷人主观还是有一定的影响. 

发展等级的打分不求全面, 即根据"特征"中 4 项, 下列 16 点中若干突出点按等评分: 

- 深刻
    1. 透过现象看本质: 能力会随社会阅历增长而增长, 较难突破. 
    2. 揭示事物内在的因果关系: 使用丰富的因果论证.  
    3. 观点具有启发作用: 对当代青年的启示需要点明, 作文结构中包含, 详见下文. 
- 丰富
    1. 材料丰富: 材料种类多样新颖且切题. 
    2. 论据充足: 字面意思. 
    3. 形象丰满: 需要对典型人物立体化, 不能仅描写其单一特征品质.
    4. 意境深远: 与文学积累量相关, 有一定难度.  
- 有文采
    1. 用词贴切: 使用一些书面的, 有学术风的"高级"词汇. 
    2. 句式灵活: 长短句等句式的使用. 
    3. 善于运用修辞手法: 字面意思. 
    4. 文句有表现力: 文章具有张力与气势, 可以使用排比句等技巧, 较难实现. 
- 有创意: 仁者见仁智者见智, 较难实现, 此处不局限各位的创意, 故留白. 
    1. 见解新颖. 
    2. 材料新鲜. 
    3. 构思精巧. 
    4. 推理想象有独到之处. 
    5. 有个性特征. 

从评分细则就可以看出, 实际上所谓的文采对作文的影响是极其有限的, 不超 3 分. 其作为锦上添花的因素而存在, 而非主要得分因素. 认真打磨文章内容与结构, 比文采更重要.

注意, 出现错别字, 1 字扣 1 分, 重复不计, 上限 5 分; 标点符号出现 3 处以上错误的酌情扣分; 不足字数者, 每少 50 字扣 1 分; 无标题扣 2 分. 字数严重不足的情况请查阅官方资料. 

## 审题

审题就是得出中心论点的过程. 大致分为以下几步:

1. 划分层次. 确定层与层之间的逻辑关系. 任一标点符号处均可能分割, 无需整句. 一说也可暴力划分, 每一句作为一层, 但实际上这样做不总正确. 
2. 标划关键词. 这是写作的中心, 需要在原文中反复出现. 
3. 联系多个关键词. 确定关键词间的逻辑关系. 
4. 联系现实生活与当下. 得出立意与中心论点. 

可以看出, 作文实际上就是顺着材料的思路行文, 而非主观臆断, 创造许多所谓"高级"立意. 

## 结构

想写好一篇议论文, 需要良好的结构. 最基础的结构可能为:

1. 标题: 一行.
2. 开头段: 开门见山, 概括材料 + 中心论点. 
3. 3 个论证段: 分论点 + 论据 + 论证 + 总结. 
4. 结尾段: 总结上文 + 联系时代 + 青年做法. 

当然, 你也可以对这个结构进行优化, 比如将开头扩展为名言 + 概括材料 + 联系现实 + 中心论点的形式, 在分论点前使用比喻句或引用名言, 在论证段间使用过渡句与过渡段, 将结尾拆分为联系时代(青年做法) + 排比收尾两段等. 当然, 也有很多高级, 可选择的段落, 如在开头段下方加入辨析段, 对材料中的现象下定义; 或将第三个论证段替换为辨析段, 结合实际进行论证等. 

## 题型分类

### 思辨作文

材料中明确提出两个有关联的事件或现象, 要求你进行辨析并得出自己的观点. 实际上二者的关系无非以下三种:

1. 与: 二者都要, 相互结合, 相互促进. 第一段可以使用"A 是 B 的基础(只有 A 才能 B)", 第二段使用"B 是为了更好的 A", 第三段可以考虑"只有当 A 与 B 相互结合, 才...". 
2. 或: 分类讨论, 某种情形选用前者, 某种情形选用后者, 即有时 A , 有时 B . 
3. 非: 肯一否一, 二者只能选其一, 需要明确分出好坏优劣, 一般用于完全矛盾对立的事件或现象. 可以通过"诚然 A 固然... , 但是 B ..." 的句型来表达. 

注意, 关系的选择必须依照材料中的思路进行, 且每一种关系都需要在文章中提及二者. 还有, 必须立场鲜明地选择其中一个, 不能同时支持多种关系.
