# 作文

## 议论文基本要素

高考作文普遍建议写议论文. 议论文三大要素为论点, 论据, 论证. 简单来说, 论点是文章的观点看法, 分为中心论点与分论点. 一篇作文一般只有一个中心论点, 但可以由中心论点拆分出多个分论点, 用以支撑中心论点. 那么, 如何证明论点的正确性? 借助论据, 即议论时的"证据". 论据分为事实论据与道理论据, 事实论据包括事例与数据, 而道理论据一般为名人名言, 俗语格言, 权威意见, 或公认的常识与普遍规律等. 想要令论据服务于论点需要一定的过程及方法, 即论证与论证方法. 常见的论证方法有:

1. 举例论证: 即举典型事例来证明观点. 
2. 道理论证(引用论证): 引用名人名言, 俗语格言等来证明观点.
3. 对比论证: 把两种相似或相对的事物, 观点放在一起进行比较. 既可横向对比(不同对象间)也可纵向对比(同一对象的前后变化). 
4. 比喻论证: 寻找通俗易懂且存在本质上的相似点的喻体, 进行比喻.
5. 因果论证: 阐明何种原因导致了特定结果, 或由既定结果追溯其产生原因.
6. 类比论证: 将多个本质不同, 但某些属性相似的对象进行比较, 由其一具有此属性从而得到另一也可能具有此属性.  
7. 假设论证(归谬法):  先假设事件没发生, 从反面推得造成的后果与影响; 或在驳论文中, 假设对方观点正确, 直到推出一个明显荒谬, 违背常理的结论, 从而反证对方观点错误. 
8. 数据论证: 列出准确, 具体的数据.

## 结构

想写好一篇议论文, 需要良好的结构. 最基础的结构可能为:

1. 标题: 一行.
2. 开头段: 概括材料 + 中心论点. 
3. 3 个论证段: 分论点 + 论据 + 论证 + 总结. 
4. 结尾段: 总结上文 + 联系时代 + 青年做法. 

当然, 你也可以对这个结构进行优化, 比如将开头扩展为名言 + 概括材料 + 联系现实 + 中心论点的形式, 在分论点前使用比喻句或引用名言, 在论证段间使用过渡句与过渡段, 将结尾拆分为联系时代(青年做法) + 排比收尾两段等. 当然, 也有很多高级, 可选择的段落, 如在开头段下方加入辨析段, 对材料中的现象下定义; 或将第三个论证段替换为辨析段, 结合实际进行论证等.
